# Research: App Initialization & Dashboard

## Technical Context Decisions
All technical choices are dictated by the project constitution.

- **State Management**: Zustand (mandated)
- **Data Persistence**: Local Storage via backend IPC (mandated)
- **Data Format**: JSON Resume schema (mandated)
- **Data Validation**: Zod (mandated)
- **Styling**: TailwindCSS (mandated, custom CSS prohibited)
- **Architecture**:
  - Renderer: React + Feature-Based architecture
  - Backend: Electron + MVC architecture
- **Testing**: Jest using TDD (mandated)

## Open Questions Resolved
No outstanding technical ambiguities. The constitution provides a strict and clear framework for all major technical decisions.
